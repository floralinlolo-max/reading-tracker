# 我的閱讀日曆

給學生記錄閱讀的網頁：日曆上貼著每天讀的書、記錄頁數與心得、讀完有慶祝動畫，還有會跟著閱讀量長大的夥伴和換裝小舖。

- 學生頁：https://floralinlolo-max.github.io/reading-tracker/ （用老師加入名單的 Google 帳號登入）
- 老師後台：https://floralinlolo-max.github.io/reading-tracker/admin/ （看全班閱讀量、管理學生名單）

登入和資料庫用 Firebase（和「班級百寶箱」共用同一個專案）。資料庫規則決定誰能看什麼：學生只能讀寫自己的資料，老師（班級百寶箱的擁有者／管理者）可以看全班。
